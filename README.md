# KairosTools

一个参考BoosterX功能，结合AI打造的轻量Windows系统优化工具。

## 功能

- 基础优化
- 现代流畅的 Fluent Design 界面
- 兼容 Windows 10 / 11

## 下载

前往 [Releases](https://github.com/Sh1r0ko0721/KairosTools/releases) 下载最新版本的 `KairosTools.exe`，双击运行即可。

## 系统要求

- Windows 10 1809 或更高 / Windows 11
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- 需要以管理员身份运行

## 从源码构建

```bash
git clone https://github.com/Sh1r0ko0721/KairosTools.git
cd KairosTools
